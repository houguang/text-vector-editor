# GlyphCut · 文字转矢量线条编辑器

GlyphCut 是一个基于 Tauri 2、Rust 和原生 Canvas 的桌面文字轮廓编辑器：输入文字后选择系统字体，将字形转换为可编辑的矢量轮廓，并通过节点、曲线和笔画工具进行整理。

## 功能

- 系统字体列表、搜索与字重选择，默认优先中文楷体。
- 将单行或多行文字转换为独立的闭合轮廓。
- Canvas 画布上的选择、框选、平移、缩放、适应视图和节点编辑。
- 点切断、连接端点、直线闭合、圆弧闭合、插入节点、删除节点。
- 双击空白画布可在指定位置追加文字。
- 撤销 / 重做，支持选中内容或全部内容导出 SVG。
- 笔画库支持将选中的闭合路径保存为笔画、编辑名称和例字，并批量导出。

## 开发

```bash
npm install
npm run tauri dev
```

运行测试：

```bash
npm test
```

生产构建：

```bash
npm run tauri build
```

前端入口为 `src/index.html`，Tauri 静态资源目录为 `src/`。字体枚举、字体轮廓化和 SVG 写盘由 `src-tauri/` 中的 Rust 命令完成。

## 快捷键

- `Ctrl+Enter`：转换文字
- `Ctrl+Z` / `Ctrl+Y`：撤销 / 重做
- `Ctrl+K`：点切断工具
- `Ctrl+J`：连接选中的端点
- `Ctrl+E`：导出选中；`Ctrl+Shift+E` 导出全部
- `F`：适应视图
- `I`：插入节点
- `Esc`：退出工具或清除选择
